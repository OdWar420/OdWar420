I build the tools I wish existed, then make them survive real hardware.
Most of it is about keeping a home machine and the AI agents on it in line:
security, memory, and fixing things that the vendor never will.

**Rule of the house:** if it is not measured, it does not work yet.

### What I am building

**[Tortugarr](https://github.com/tortugarr/tortugarr)** — Every pirate needs a harbor.
A streaming service you own: Android TV and phone app for Jellyfin, plus one command
that sets up the whole *arr stack. Browse, pick the exact release, watch. From the couch.

**[Sentinel Armory](https://github.com/sentinelarmory)** — Small, sharp tools that keep a home rig in line.
A security centre that AI agents can operate, one shared brain for every agent,
and a gatekeeper that decides what gets written to it.
Mostly private for now. What is public works:
[sentinel-warden](https://github.com/sentinelarmory/sentinel-warden) gives iCUE control of ASUS Aura again.

**[UE5-AFP](https://github.com/ue5afp)** — From a written idea to a playable Unreal Engine game.
Rust modules, native Windows, local AI. Private while it grows up.

**[AXIOM](https://github.com/OdWar420/axiom-public)** — A tiny capability-secured OS for RISC-V,
built milestone by milestone. Research toy, but it boots.
